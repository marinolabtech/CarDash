Privacy Policy - CarDash System

Valid for CarDash Server & CarDash Bridge | July 2026

Introduction

This Privacy Policy applies to the entire CarDash System ecosystem, including the CarDash Server (for smartphones) and CarDash Bridge (for tablets/infotainment) applications.

The system is designed to operate as an integrated unit, enabling secure data exchange between your own Android devices within a vehicle.

System Structure

CarDash Server (Smartphone)

Acts as the data source (Calls, Contacts, SMS, Notifications, and GPS).

CarDash Bridge (Tablet)

Acts as the receiver and user interface (Dashboard, Radio, Navigation).

Data Collection and Purpose

The system accesses and exchanges the following data exclusively to enable the infotainment features:

  • Caller ID and Contacts: To display and manage calls on the tablet.
  • System Notifications: To show incoming messages (e.g., WhatsApp) on the Dashboard.
  • GPS Location: For navigation and vehicle retrieval (Parking Tracker).
  • Web Radio Data: Only for multimedia streaming requested by the user.

Data Security and AES-256

All communication between the Server and Bridge apps takes place over a local Wi-Fi connection encrypted with AES-256 standards. No personal data is ever sent to external servers, third parties, or the developers. The data remains under the user's exclusive control within their private local network.

Google Play Billing

CarDash Server manages in-app purchases via Google Play Billing. Payment information is handled exclusively by Google; the application only receives confirmation of the license status to unlock Premium features on both connected devices.

User Rights and Control

The user has full control over the permissions granted to both applications via Android system settings. Revoking permissions will result in the deactivation of the respective mirroring features.
